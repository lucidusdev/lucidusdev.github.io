Local Tuya Integration

That's (almost) my full intention for HA -- turning off light when internet is down.

There're two popular Tuya integration, localtuya, available in HACS and tuya-local only in github. I started with localtuya, it's OK but lots of work. tuya-local is much much easier to work with, and actively maintained. After installation just follow the instruction it will load all devices from tuya cloud and set them up.

History DB in memory

By defaults, HA saves all events in /config/home-assistant_v2.db. I don't care much about these data, so I put the db on ram(/tmp on host).

  1. create /etc/init.d/hass_db on OpenWrt

    /hass_db is /tmp/hass_db in OpenWrt host.

    Resource usage

    The HA docker instances uses about 400-500MB RAM and almost no CPU.

    With both home assistant and owntone running. No problem on this 2G RAM router but can be stressful with 1GB RAM.

    history DB is about 10-15MB per day after commit_interval: 15. Default is 5 (save every 5 seconds).
