RGB Led Control In Openwrt

Posted on 2026-06-05

Set RGB color in fixed or blinking mode from command line.

Locate led devices.

write brightness value to brightness to set R G B, write trigger value to trigger for special effect(blink)

Fixed Color

set color to yellow(rgb 255 0 0). maximum brightness is 255 per max_brightness

set to light purple(rgb 100 0 100)

Blink

timer based

Set tigger to timer . There're other triggers available, mostly network activity based.

Run

to see all available options.

To blink red, 500ms on and 2000ms off.

echo 0 > brightness will reset trigger to none.

when a color is set to blink(timer trigger), it's on full brightness and can't be adjusted. Available colors are:

  • red green blue

  • yellow cyan purple

  • white

can't blink light yellow light red etc..

It's also possible to set a base color with another led blinking, for example, blue always on and red is blinking, which will result a blue---purple---blue---purple... pattern.

heartbeat trigger

It's supposed to blink with cpu load. 

#clean old status
echo 0 > /sys/class/leds/red:status/brightness
echo 0 > /sys/class/leds/green:status/brightness
echo 0 > /sys/class/leds/blue:status/brightness
#heartbeat red
echo heartbeat > /sys/class/leds/red:status/trigger
